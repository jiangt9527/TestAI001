# TestAI001 — 个人 AI 工作空间

这个仓库是我与 GitHub Copilot AI 助理 **Coda** 的长期协作空间。

仓库作为持久化记忆与工作台，让 AI 助理在每次新对话中都能恢复上下文、延续角色、继续工作。

## 核心文件

| 文件 | 用途 |
|---|---|
| [`AGENTS.md`](./AGENTS.md) | AI 助理定义：角色、工作方式、记忆规则、收尾协议 |
| [`MEMORY.md`](./MEMORY.md) | 长期记忆：项目背景、偏好、决策 |
| [`memory/log.md`](./memory/log.md) | 会话日志：每次对话做了什么 |

## 如何开始新对话

> 告诉 Copilot：「请先读 AGENTS.md 和 MEMORY.md，然后继续我们的工作。」
